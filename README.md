# Customer Churn Prediction System

An end-to-end Machine Learning project that predicts customer churn in the telecommunications industry using Python and Scikit-Learn.

## 📌 Project Overview
Customer churn is a critical metric for subscription-based businesses. This project builds a binary classification model using **Random Forest** to identify high-risk churn customers, allowing businesses to take proactive retention measures.

## 🛠️ Tech Stack & Tools
* **Language:** Python 3.x
* **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
* **Model:** Random Forest Classifier
* **Dataset:** Telco Customer Churn Dataset

## 📊 Workflow & Methodology
1. **Data Preprocessing:** Handled missing values, encoded categorical features, and applied `StandardScaler` for numeric normalization.
2. **Feature Engineering:** Identified key drivers impacting retention (contract type, tenure, monthly charges).
3. **Model Evaluation:** Evaluated performance using Precision, Recall, F1-Score, and ROC-AUC metrics.
